# QUẢN LÝ DOANH NGHIỆP — V1

## Mục tiêu
Bản V1 chuyển giao diện Module 2 trong file HTML ban đầu thành khung web quản lý nhiều module, chạy tĩnh trên GitHub/Netlify.

## Có sẵn
- Dashboard
- Khách hàng / Đại lý
- Thêm / sửa / xóa khách hàng
- Trường thông tin tùy chỉnh
- Nhiều đầu mối liên hệ
- Tìm kiếm và lọc khách hàng
- Các module khung: Sản phẩm, Đơn hàng, Giao hàng, Công nợ, Báo cáo, Cài đặt
- Lưu dữ liệu khách hàng bằng localStorage của trình duyệt

## Chạy
Mở `index.html` trực tiếp hoặc deploy cả thư mục lên Netlify.

## Lưu ý
localStorage chỉ phù hợp cho bản prototype/V1. Khi nhiều người dùng cùng hệ thống, cần thay bằng database + đăng nhập/phân quyền.
